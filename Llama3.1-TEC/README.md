## 🎯 **Sobre esta Capacitación**

El **Tecnológico de Monterrey (TEC)**, en colaboración con **Meta**, presenta un programa especializado de capacitación en el modelo de IA **Llama 3.1** dirigido a estudiantes, profesores e investigadores. Este programa combina fundamentos teóricos con aplicaciones prácticas para formar especialistas en IA generativa y modelos de lenguaje.

### 🚀 **Objetivos del Programa**
- **Capacitar** estudiantes y profesionales en tecnologías Llama 3.1
- **Desarrollar** proyectos de IA aplicados a la industria y educación
- **Implementar** soluciones innovadoras con modelos de lenguaje
- **Formar** especialistas en IA generativa y fine-tuning

### 👨‍🏫 **Instructor**
**Pablo Álvarez** - Especialista en IA y Machine Learning
- 🌐 **Multivérsica**: [https://multiversica.com/](https://multiversica.com/)
- 🎓 **Experiencia**: Implementación de soluciones IA en sector educativo y empresarial
- 🏫 **Especialización**: Modelos de lenguaje para aplicaciones académicas e industriales

## 🚀 **Inicio Rápido**

### 1️⃣ **Clonar Repositorio**
```bash
git clone https://github.com/alvarezpablo/Llama-Tech-Talks.git
cd Llama-Tech-Talks/Llama3.1-Sicyt-AR-2025
```

### 2️⃣ **Configurar Entorno**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# o
.\venv\Scripts\activate   # Windows

pip install -r requirements.txt
```

### 3️⃣ **Configurar Token Hugging Face**
```bash
# Opción 1: Variable de ambiente
export HF_TOKEN="tu_token_aqui"

# Opción 2: En Kaggle/Colab (ver notebooks)
```

### 4️⃣ **Comenzar con Módulo 1**
```bash
# Abrir presentación
open "módulo 1/Módulo 1 - Fundamentos de Llama 3.1 y Transformers.pdf"

# Leer documentación
open "módulo 1/README.md"

# Ejecutar notebooks
jupyter lab "módulo 1/"
```
